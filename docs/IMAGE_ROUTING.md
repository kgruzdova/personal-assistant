# Автоматическая генерация изображений

Бот использует OpenAI напрямую. Модель из `OPENAI_MODEL` получает историю диалога и выбирает ответ текстом или вызов инструмента генерации изображения. Обычный текстовый запрос требует одного обращения к модели. В режиме `/mode rag` модель также получает найденные фрагменты документов.

Примеры запросов в Telegram:

- «Сделай открытку с рыжим котом и надписью „С днём рождения!“»
- «Нужна обложка к этому посту» — после обсуждения поста.
- «Сделай афишу мастерской Роса по данным из базы знаний» — в режиме RAG.

Для явного запроса также доступна команда `/image описание`. Перед фотографией бот отдельным сообщением показывает «Улучшенный промпт на английском языке» — точный текст, переданный генератору. Это работает и с голосовыми запросами; запрошенные надписи на самой картинке сохраняются на исходном языке. Длинный промпт отправляется несколькими сообщениями целиком. Вопросы о рисовании и просьбы написать промпт получают текстовый ответ.

Дополнительные настройки в корневом `.env`:

```dotenv
OPENAI_IMAGE_MODEL=gpt-image-1
OPENAI_IMAGE_SIZE=1024x1024
OPENAI_IMAGE_QUALITY=medium
```

Ключ берётся из `OPENAI_API_KEY`. Нужен действующий ключ с доступом к выбранным текстовой и графической моделям. После изменения кода или настроек перезапустите `python main.py`.

Локальная проверка без сетевых запросов:

```powershell
.\venv\Scripts\python.exe -m pytest -q tests/test_image_generation.py tests/test_text.py tests/test_rag.py
```

Проверки подменяют ответы OpenAI и Telegram: они проверяют вызов инструмента, передачу истории и RAG-контекста, сохранение base64-картинки, отправку фото и удаление временного файла. Они не подтверждают доступность моделей в конкретном аккаунте.
